the pipeline

      
One URL in. One report out.

      
The pipeline is small on purpose. Each stage is a local model or a plain HTTP call, and every stage has a fallback.

    

    

      

        
Fetch

        
Impersonated TLS first, then the platform API, then a real browser with your session. oEmbed is the floor.

        curl_cffi, camoufox
      

      

        
Transcribe

        
The audio goes to faster-whisper at int8. No GPU needed, no queue, nothing leaves the machine.

        11x realtime on 16C
      

      

        
Read

        
Every frame and image goes to a local vision model: what the scene shows, plus all on-screen text, verbatim.

        LFM2.5-VL 1.6B, Q8_0
      

      

        
Gather

        
Top comments with their like counts, plus a consensus score: who agrees, who pushes back, who is passing through.

        transparent heuristic
      

      

        
Write

        
One markdown report and one JSON. Markdown for the LLM to read, JSON for the machine to use.

        .md + .json

why local

      
Built for the machine you already have.

    

    

      

        
No GPU fight.

        
CPU-only, no torch, no cloud. Your GPU stays free for your llama.cpp server; scry takes the spare cores and runs while you do. Whisper small at int8 is fast enough that it stops being a constraint.

        STT small int8: 11.3x realtime on a Ryzen 7 7800X3D
      

      

        
Nothing leaves the box.

        
Your cookies in, a report out. Models live in ~/.cache, run data in /tmp. No API key, no account, no telemetry.

      

      

        
Logged in as you.

        
Three tiers: impersonated TLS, then the API, then a real browser carrying your session. It works because it looks like you.

      

      

        
It ships its own manual.

        
The package bundles a SKILL.md following the agentskills.io standard. One command installs it into your agent’s skills directory, and the agent learns the flags, the caveats, and how to read the consensus score.

        scry skill --path ~/.agents/skills
      

    

  






  

    

      
compare

      
Where scry sits.

      
Downloaders get you the file. Scraping APIs get you the metadata, at $450 a month. A general agent with a cloud browser can do all of it, if your model is good enough and your bills do not care. scry does the whole job on your CPU, for free, in one command.

for agents

      
Agents get a manual, not a guess.

      
An agent that cannot see a video is a guesser. With scry it has a report. Install the bundled skill once, and any agent that scans that directory knows which flags exist, what the consensus score means, and when a result is a floor and not the truth.

      
Standard: agentskills.io. Discovered by pi, Claude Code, Codex, Cursor, Gemini CLI.

    

    

      $ scry skill --path ~/.agents/skills

      Skill installed: /home/you/.agents/skills/scry/SKILL.md

      Make sure your agent harness scans that directory for skills

      (cross-harness standard: ~/.agents/skills).
    

  






  

    

      
install

      
Two commands.

    

    

      

        uv tool install “scry-social[vision]”
        
      

      

        scry setup --all
        
      

    

    
One-time: the Camoufox browser and the vision model land in ~/.cache/scry. pip works too: pip install “scry-social[vision]”. Cookies from your browser (Netscape format) are optional but strongly recommended.
